# A General Quantile-Based Lifetime Performance Index — reproduction code

`R` code reproducing every table, figure and reported number in

> Alkhuffash, O. and Kuş, C. *A General Quantile-Based Lifetime Performance
> Index and its Application to the GIE Distribution under Progressive
> First-Failure Censoring.*

The paper proposes a lifetime performance index built from the median and the
interquartile range,

$$C_L^{\xi} = \frac{\xi(0.5) - L}{\xi(0.75) - \xi(0.25)},$$

as an alternative to the classical moment-based index $C_L^{M} = (\mu - L)/\sigma$,
which is undefined whenever the lifetime distribution has no finite variance.
Inference is developed for the generalized inverted exponential (GIE)
distribution under progressive first-failure censoring (PFFC).

## Quick start

```r
install.packages(c("numDeriv", "statmod", "ggplot2", "tidyr", "dplyr",
                   "patchwork", "future", "furrr", "progressr", "progress"))
```

```
cd code
Rscript run_all.R quick    # validation, Table 1, Figures 1-3, both applications
Rscript run_all.R          # the above plus the simulations
```

From the RStudio console instead, set the working directory to `code/` and use
`QUICK <- TRUE; source("run_all.R")` — `source()` passes no command-line
arguments, so without that the full run would start by accident.

The quick pass takes a few minutes. The full run takes a few hours; the two
heavy scripts run in parallel by default and all four report progress with an
estimate of the time remaining.

## What is here

```
code/                 all R code; see code/README.md for the per-script detail
code/validation/      checks of the paper's analytical results against
                      independent numerical computation
tables/               empty; the scripts write LaTeX table fragments here
figures/              empty; the scripts write EPS and PDF figures here
```

Only source is tracked. Everything the scripts produce — the CSV results, the
LaTeX fragments, the figures — is regenerated by running them, so none of it is
committed. `code/README.md` documents which script produces which table and
figure, the random seeds, and the estimation details.

The manuscript itself is not in this repository. `code/README.md` refers to it
in a few places; those references are to the paper as submitted.

## Two things worth knowing

**Every closed form in the paper is used, not merely stated.** The closed-form
moment for integer shape, the fixed-point iteration for the maximum likelihood
estimate of the scale, the closed-form Hessian, and the analytical derivatives
of the index are all on the path that produces the reported numbers. Numerical
differentiation is used for exactly one thing — the gradient of the
moment-based index, whose value depends on quadrature — which is the fallback
the paper itself describes. The `validation/` scripts check each of these
against an independent numerical calculation and stop with an error if a check
fails.

**The scripts write the manuscript's numbers, not just its tables.** Each
simulation writes a LaTeX table fragment and a file of `\newcommand`
definitions covering every number quoted in the running text. The manuscript
`\input`s both, so re-running a script updates the prose together with the
table it describes and the two cannot fall out of step.
